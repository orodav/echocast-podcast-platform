# EchoCast

EchoCast is a database-driven podcast platform designed to manage creators, podcasts, episodes, and user interactions.

The platform is designed to support podcast publishing, subscriptions, playlists, listening history, reviews, donations, creator moderation, and analytics.

## Database

EchoCast is built around a relational MySQL database designed to preserve data consistency and historical information.

The database schema defines users, creators, administrators, podcasts, episodes, categories, playlists, listening activity, reviews, subscriptions, donations, and creator suspensions through referential and domain constraints.

## Tech Stack

- Java
- MySQL
- Maven
- Swing

## Development

EchoCast is currently under development.
